# EatEasy interface

A Portuguese restaurant booking app with warm cream surfaces, a burgundy navigation rail and Georgia headings. Body and form text use Segoe UI. Keep this hospitality identity separate from the portfolio and other tools.

Restaurant cards lead with a name, cuisine, location and price; booking is the primary action. Bundled photographs are illustrative editorial imagery, not verified photographs of each restaurant. Label that once near the list and on the reservation page.

The desktop dashboard contains scrolling lists and forms. Mobile navigation stays compact and page actions remain reachable. Reservations use Europe/Lisbon time, preserve the entered values on validation errors and show a concise date/time/party summary before submission.

Use server sessions, database-backed customer/admin permissions and CSRF-protected POST forms for writes. Never perform cancellation or restaurant removal through a GET link. Report outcomes in the page instead of JavaScript alerts. Sample data is explicitly fictional; the PHP application remains separate from the optional legacy static export.
